#Workday Finance Application

Project Objective

The objective of this project is to leverage AI-driven integration across ERP systems such as Workday to streamline financial operations, 
where HR, payroll, cost centers, and financial reporting intersect. By combining payroll calculation audits, grant cost allocations, 
and monitoring of grant cost allocations to ensure accurate records in ERP systems,this project supports gap analysis and financial risk management
in planning and budgeting.

In addition, the ad hoc cost center-sample data file is used to identify each department’s cost allocations for sick leave, vacation, and FICA percentages
by extracting data from the cost center. Calculation percentages are identified in column R, with comment notes provided for in-depth review of the processed 
transactions in Workday systems.


Project Scope

Review payroll calculation results

Monitor payroll costing allocations

Analyze split-funded payroll distributions

Review multi-grant salary allocations

Support gap analysis and financial risk management
